Audio troubleshooting for MATE 2.50

For a silent stereo USB DAC, start with Force 2 channel audio output by itself. It keeps the game's original 48 kHz, 24-bit PCM in a 32-bit container.

If exclusive playback is still silent, also try 16-bit PCM for WASAPI exclusive mode. This requires the DAC to accept 48 kHz 16-bit PCM in exclusive mode.

If 16-bit stereo works but loud passages distort, try Stereo PCM16 headroom. The whole mix will be quieter. Compare the same passage on the same device.

If that helps only a little, try Front L/R only for stereo output with headroom unchecked. Listen for both distortion and any missing game sounds.

For the cabinet headphone mix, choose Rear L/R only for headphones and test in a song. The title screen may be quiet because this uses the game's separate headphone feed.
